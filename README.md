# Arduino Nano Stepper Clock

Arduino Nano project combining a stepper motor with real-time clock and sensors.

## Hardware
- 28BYJ-48 stepper motor (4096 steps/rev in half-step mode)
- DS1302 RTC
- Hall effect sensor (OUT on D2)
- Active buzzer

## Software
- Arduino IDE, AccelStepper library (`HALF4WIRE`)
